# Technopreneurship 101 multiple-choice reviewer

120 multiple-choice questions, with 40 questions from each supplied module.

- Open directly to the questionnaire; one question at a time.
- Click an answer for immediate feedback.
- A correct answer turns green.
- An incorrect selection turns red and the correct answer turns green.
- Each answer includes an explanation and source-page reference.
- Filter by module, navigate questions, review scores, or restart the selected module.
- Responsive layout, keyboard controls, and text labels supplement color feedback.
- No backend, analytics, external scripts, or account required. Answers are held only in the current tab.

## Sources

The question bank is an independently written study aid based on the three supplied Technopreneurship 101 modules (41 PDF pages). The original PDFs, their images, and raw extracts are **not included**. Module validation thresholds are instructional examples, not universal benchmarks.

## Files

`index.html` embeds the complete quiz and works offline. `questions.json` contains its editable question bank. `.nojekyll` enables static GitHub Pages delivery, and `.gitignore` excludes PDF source files.

## Hosting

Publish the root of the `main` branch using GitHub Pages. No custom workflow or build is required.
